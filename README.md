# Student Performance Analysis Using Machine Learning

## Overview

This project focuses on analyzing and predicting student academic performance using machine learning techniques. The study uses student interaction, assessment, and academic information to identify patterns associated with student outcomes.

The project also introduces two proposed composite indicators:

- **AI Learning Resilience Score** – measures student learning resilience based on academic performance, online learning engagement, learning consistency, and assessment participation.
- **Academic Pressure Score** – estimates academic pressure based on course workload, assessment load, and previous academic attempts.

Based on these indicators, the project provides targeted intervention recommendations to support students who may require additional academic assistance.

## Objectives

- Analyze student academic and learning behavior.
- Explore relationships between student engagement and academic outcomes.
- Develop an AI Learning Resilience Score.
- Develop an Academic Pressure Score.
- Identify students who may require academic support.
- Provide personalized intervention recommendations.
- Visualize student resilience and academic pressure patterns.

## Dataset

The project uses data from the Open University Learning Analytics Dataset (OULAD).

The analysis uses information related to:

- Student assessment performance
- Virtual Learning Environment (VLE) interactions
- Student engagement
- Course and assessment information
- Previous academic attempts
- Studied credits

Large dataset files are managed using **Git Large File Storage (Git LFS)**.

## Methodology

The overall workflow consists of:

1. Data preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Student engagement analysis
5. AI Learning Resilience Score calculation
6. Academic Pressure Score calculation
7. Student categorization
8. Intervention recommendation
9. Data visualization

## AI Learning Resilience Score

The proposed resilience score combines normalized indicators related to:

- Average assessment performance
- Online learning engagement
- Learning consistency
- Assessment participation

The resulting score is categorized into:

- Very Low
- Low
- Moderate
- High

## Academic Pressure Score

The proposed academic pressure score considers factors such as:

- Studied credits
- Assessment load
- Previous academic attempts

The resulting pressure level is categorized into:

- Low
- Moderate
- High
- Very High

## Intervention Framework

The project provides intervention recommendations based on the identified student profile.

Examples include:

- Academic mentoring
- Improving online learning engagement
- Structured study planning
- Assessment management
- Workload management
- Regular academic progress monitoring
